# ACADEMIC_USER.md — 用户长期画像

## 职责边界

本文件只保存长期稳定的用户画像和研究偏好。它不保存当前项目列表、文献数量、专题资产统计或临时优先级。

- 当前项目状态：按 `ACADEMIC_WORKSPACE.md` 路由读取 Vault `index.md`、项目 Context Packet、项目作战室或 dashboard
- 具体理论原则：见 `rules/axioms/INDEX.md`
- 写作风格细则：见 `rules/ACADEMIC_COMMUNICATION.md`
- 任务执行方式：见 `rules/skills/SKILL_INDEX.md`

## 基本画像

- **身份**：商学院战略管理与运营管理学教授
- **目标期刊**：AMJ、SMJ、ASQ、Organization Science、MSOM、AMR 等 UTD24/FT50 期刊
- **时区**：东八区（GMT+8）
- **称呼**：教授、老师，或直接“你”
- **主要工作语言**：中文用于讨论、诊断和理论构建；英文用于论文正文

## 研究取向

用户偏好理论驱动型实证研究。好的项目必须先有清楚的理论张力、机制链条和贡献定位，实证设计用于支撑理论判断，而不是替代理论判断。

长期研究兴趣集中在战略管理、运营管理、公司治理、产品安全、制度环境与企业决策的交叉地带。常见理论资源包括高阶理论、行为理论、制度理论、代理理论、组织学习和 CEO 认知特质。

三类长期专题尤其重要：产品召回、竞业协议/制度冲击、共同所有权。涉及这些专题时，不要只凭通用知识回答，应读取 Vault 中的专题索引、概念页、论证卡和项目材料。

## 方法偏好

- 自然实验和可信制度冲击优先。
- DID、IV、RDD、匹配、生存分析等方法服务于研究问题，而不是展示技术复杂度。
- 平行趋势需要图形证据和安慰剂检验共同支撑。
- 异质性处理效应问题不能默认用传统 TWFE 解释，应考虑 Callaway-Sant'Anna、Sun-Abraham 等现代 DID 诊断。
- 生存分析以 Cox 比例风险模型为基准，不默认把时间变量做 OLS 对数转换。
- 内生性来源、构念-测量对齐和稳健性设计必须被明确讨论。

## 工具偏好

- **Stata**：主力工具，用于面板数据、DID、IV、匹配、生存分析和论文表格。
- **Python**：辅助工具，用于数据清洗、文本分析、可视化和部分机器学习任务。
- **R**：默认不使用，除非用户明确要求或某项方法只能通过 R 高质量实现。
- **Zotero**：文献管理。
- **Obsidian Vault**：知识库、概念页、论证卡、项目 Context Packet 和证据链。

## 写作与沟通偏好

用户偏好直接、结构化、有判断的交流。不需要客套、铺垫或泛泛总结。学术写作追求简洁、有力、能承担理论判断，避免翻译腔、公式化表达和空洞修饰。

讨论理论时，需要区分三件事：文献已经证明了什么、用户项目在连接什么、当前推理中哪些仍是待验证判断。

讨论实证时，需要区分显著结果、可信证据和理论解释。显著系数本身不是贡献，也不自动构成证据。

## 需要避免

表达和写作禁忌见 `rules/ACADEMIC_COMMUNICATION.md`。本文件只保留长期画像，不把当前项目状态、临时判断或阶段性优先级写入用户画像。

## 使用注意

不知道就说不知道。需要查证时先查证。给出判断时说明根据。用户要的是高质量学术协作，不是语气热情的泛化建议。
