# w06: Paragraph Triad Structure — 每个段落必须是完整的论证单元

## 核心原则

**学术论文的每个段落都应包含主题句、支持句、结尾/衔接句的三段论结构，独立承载完整的论证单元，同时与其他段落形成有机联系。**

## 三段论结构

```
┌─────────────────────────────────────────────────────────┐
│  主题句 (Topic Sentence)                                  │
│  → 点明段落主旨，既是读者入口，也是论证支点                  │
├─────────────────────────────────────────────────────────┤
│  支持句 (Supporting Sentences)                            │
│  → 解释、补充、举例，引用数据/证据增强说服力                 │
├─────────────────────────────────────────────────────────┤
│  结尾/衔接句 (Closing/Linking Sentence)                   │
│  → 总结本段、呼应主题句，或自然过渡到下一段                   │
└─────────────────────────────────────────────────────────┘
```

## 各 Section 的段落策略

| 章节 | 主题句策略 | 支持句策略 | 结尾句策略 |
|------|-----------|-----------|-----------|
| **Introduction** | 问题导入、建立张力 | 文献进展→缺口→后果 | 引出本文解决方案 |
| **Theory** | 陈述假设/机制 | 理论推导→文献支撑→逻辑链条 | 过渡到假设形式 |
| **Methods** | 描述方法选择 | 样本→变量→模型→识别 | 说明稳健性安排 |
| **Results** | 报告核心发现 | 系数→显著性→效应大小 | 过渡到机制/边界检验 |
| **Discussion** | 解释发现含义 | 与文献对话→理论贡献→实践启示 | 说明局限与未来方向 |

## 执行规则

1. **禁止单句段**：一两句话的段落破坏论证节奏，必须补充实证数据或权威引证
2. **主题句必须在段首**：读者只读第一句就应把握段落功能
3. **支持句必须形成环环相扣的论证链**：不是并列堆砌，而是递进推导
4. **结尾句必须有功能**：单纯重复主题句是浪费，必须增加新信息（升华、过渡、限定）

## 反例 → 正例

- ❌ （单句段，无支持）
  "CEO narcissism accelerates recall timing."
- ✅ （完整三段论）
  "CEO narcissism accelerates product recall timing. *（主题句）* This effect operates through an attention-allocation mechanism: narcissistic CEOs' heightened need for public admiration directs cognitive resources toward reputation-threatening signals, compressing the gap between defect detection and public disclosure. *（支持句-理论阐释）* Consistent with this mechanism, our text-analysis measure of narcissism correlates with faster recall initiation in high-media-coverage periods but not in low-coverage periods, suggesting the effect is driven by image concern rather than genuine risk awareness. *（支持句-实证支撑）* These findings challenge the default assumption that CEO personality effects on safety decisions are uniformly detrimental, and instead highlight the contextual dependency of trait-driven behavior. *（结尾句-升华）*"
