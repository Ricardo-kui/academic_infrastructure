# w02: One Paragraph, One Function — 每个段落必须有且仅有一个功能

## 核心原则

**一个段落同时 claim、evidence 和 transition，等于三个段落都没写清楚。**

Pollock Ch04: "每个段落应该像乐高积木一样，读者只读段首句就能把握全文结构。"

## 段落功能类型

| 功能 | 段首句特征 | 常见位置 |
|------|-----------|---------|
| **Claim** | 提出论断或假设 | Theory, Introduction, Discussion |
| **Evidence** | 呈现实证支撑 | Results, Methods |
| **Transition** | 承上启下 | Section 边界、逻辑转折处 |
| **Definition** | 界定构念 | Theory |
| **Mechanism** | 解释 why | Theory, Hypotheses |
| **Caveat** | 说明局限 | Methods, Discussion |

## 执行规则

1. **段首句必须承载段落核心信息**：读者只读段首句应该能重构论文结构
2. **禁止段中藏关键信息**：不要在段落中部或尾部才出现核心论断
3. **禁止元评论独占一段**："This section reviews the literature" 是元评论，不应独立成段
4. **段落长度控制**：英文段落 150-250 词；中文段落 200-400 字；过长必须拆分

## 段首句测试

把论文所有段首句提取出来，应该形成一篇逻辑连贯的"微缩论文"。如果读起来跳跃或重复，说明段落功能混乱。

## 反例 → 正例

- ❌ （一个段落里既有 claim 又有 evidence 又有 transition）
  "CEO narcissism accelerates recall timing because narcissists prioritize image threats. Prior research has shown that narcissistic CEOs use more first-person pronouns (Chatterjee & Hambrick, 2007). Table 2 shows our main result is significant. However, an alternative explanation is risk-seeking."
- ✅ （拆分为四个段落）
  - **Claim**: "We predict that CEO narcissism accelerates recall timing."
  - **Mechanism**: "This effect operates through an attention-allocation mechanism: narcissistic CEOs' heightened sensitivity to public image directs cognitive resources toward reputation-threatening signals, compressing the time between defect detection and public disclosure."
  - **Evidence**: "Table 2 reports the main result: a one-standard-deviation increase in CEO narcissism is associated with a 23% reduction in time-to-recall (β = -0.23, p < 0.01)."
  - **Caveat/Alternative**: "An alternative explanation attributes faster recalls to risk-seeking rather than image concern. We test and reject this interpretation in Column 3."
