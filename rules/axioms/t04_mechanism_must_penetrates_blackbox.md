# t04: Mechanism Must Penetrate the Black Box — 机制解释必须穿透黑箱

## 核心原则

**只报告 X→Y 显著而不解释 why，等于没有理论。**

Makadok: "Causal mechanism is the lever that defines why the theory's proposed relationships or effects occur."

Pollock Ch06: "Theory section必须解释 why chain，而不是堆 citation、construct 和 variable。"

## Why-Chain 标准

一个合格的机制解释必须包含至少两层：

```
构念 A（原因） → [机制 M1] → 构念 B（中介） → [机制 M2] → 构念 C（结果）
```

- **M1 和 M2 必须是行为或过程**，不能只是"影响""作用""导致"
- **每个机制必须有文献支撑或逻辑推导**，不能凭空发明
- **机制必须可观察或可推断**，不能是永远不可检验的黑箱

## 机制类型与贡献

| 机制操作 | 贡献类型 | 例子 |
|---------|---------|------|
| 引入新机制 | 新解释路径 | 将注意力分配机制引入高层梯队文献 |
| 替换机制 | 挑战既有解释 | 证明X→Y不是通过A机制，而是通过B机制 |
| 分解机制 | 精细化解释 | 将"治理效应"分解为"监督效应"和"激励效应" |
| 整合机制 | 合成新解释 | 将经济机制与心理机制结合解释同一现象 |
| 设定边界 | 条件化机制 | 说明机制在Z情境下成立，在W情境下失效 |

## 执行规则

1. **每个假设前必须有 why 段落**：不是"H1: X positively affects Y"，而是"We predict X positively affects Y because [mechanism]"
2. **机制解释必须具体到微观行为**："CEO 的信息处理偏见"优于"CEO 的认知特征"
3. **禁止 mechanism laundering**：不能说"通过影响管理者的决策质量"——这是把黑箱重新包装
4. **调节效应必须有 baseline mechanism + moderator mechanism**：解释 moderator 如何改变 baseline mechanism 的运作方式

## 反例 → 正例

- ❌ "CEO narcissism affects recall timing because narcissistic CEOs have different risk preferences."
- ✅ "Narcissistic CEOs' heightened need for admiration creates an attentional filter that prioritizes public-image threats over operational-risk signals. This attention allocation mechanism accelerates recall initiation when media visibility is high, because delays would contradict the CEO's self-constructed image of infallibility."
