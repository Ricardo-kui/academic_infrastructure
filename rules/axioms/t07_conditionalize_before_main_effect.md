# t07: Conditionalize Before Main Effect

## 原则
在提出任何主效应假设之前，先问："这个效应在什么条件下增强、减弱或反转？" 条件化框架优先于单向主效应。

## 触发场景
- 理论构建：当开始推导核心假设时
- 假设推导：当写 H1 之前，先写条件化交互假设
- 文献对话：当定位 gap 时，优先识别边界条件而非空白
- 叙事设计：当决定论文故事线时，优先考虑 contingency 而非 main effect

## 决策规则
1. 如果理论机制暗示效应强度随某条件变化 → 写交互假设，不写主效应
2. 如果文献已有主效应证据但无边界条件 → 条件化是贡献，主效应是复制
3. 如果数据允许检验交互 → 交互是核心结果，主效应是描述性统计
4. 如果审稿人要求主效应 → 报告但强调条件化框架是理论贡献

## 验证案例
- anti-SLAPP × product recall: count-primary / timing-conditional
- 共同所有权 × product recall: action-threshold reweighting 条件化框架
- CEO paranoia × time to recall: severity×paranoia 交互
- CEO regulatory focus × time to recall: action-threshold reweighting 链条
