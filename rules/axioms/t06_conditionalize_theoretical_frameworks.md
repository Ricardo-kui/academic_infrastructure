# t06: Conditionalize Theoretical Frameworks

## 核心原则

**当理论框架呈现二元对立（如 A vs B）时，应主动寻找边界条件将其转化为条件化框架（如当 X 高时 A 占优，当 X 低时 B 占优），以提升理论精确性和解释力。**

## 触发场景

- 文献中存在两个竞争性理论预测（如加速 vs 延迟）
- 现有理论框架过于简化（如单一机制）
- 实证结果不一致，暗示存在调节变量

## 决策规则

1. **识别对立框架**：明确两个竞争性预测及其理论基础
2. **寻找边界条件**：识别可能调节哪个预测占优的情境因素（如外部威胁、竞争强度）
3. **构建条件化框架**：将二元对立转化为条件化预测（如当 X 高时效应为正，当 X 低时效应为负）
4. **验证条件化框架**：通过交互效应或分组回归检验边界条件

## 例外

- 当理论本身要求绝对性（如数学定理）
- 当边界条件无法操作化或测量时

## 验证

- 检查是否从二元对立转向条件化预测
- 检查边界条件是否有理论基础
- 检查条件化框架是否可实证检验
