# w08: Supporting Sentences Chain — 支持句必须是环环相扣的论证链

## 核心原则

**支持句不是证据堆砌，而是理论阐释 → 实证支撑 → 分析论证的递进链条。每个支持句必须从前一句自然生长，用过渡词呈现逻辑关系。**

## 三层递进结构

```
Layer 1: 理论阐释 (Theoretical Elaboration)
    → 阐明主题句成立的逻辑依据或理论背景
    → 回答 "为什么这个判断在理论上是合理的？"

Layer 2: 实证支撑 (Empirical Support)
    → 引入具体数据、典型案例或权威发现
    → 回答 "有什么证据支持这个判断？"

Layer 3: 分析论证 (Analytical Argumentation)
    → 阐释证据与论点的内在关联
    → 回答 "这个证据如何证明了这个判断？"
```

## 过渡词的逻辑功能

| 逻辑关系 | 英文过渡词 | 中文过渡词 | 使用场景 |
|---------|-----------|-----------|---------|
| 递进 | Moreover, Furthermore, Additionally | 此外，而且，更重要的是 | 添加新证据或新维度 |
| 因果 | Therefore, Thus, Consequently | 因此，从而，导致 | 从证据推导结论 |
| 转折 | However, Nevertheless, Yet | 然而，尽管如此，但是 | 引入反例或限定条件 |
| 对比 | In contrast, Conversely, Whereas | 相比之下，相反地 | 对照不同情境或理论 |
| 举例 | For example, Specifically, In particular | 例如，具体而言 | 用案例或数据细化论点 |
| 总结 | In sum, Overall, Taken together | 综上，总体而言 | 收束论证，回归主题句 |

## 执行规则

1. **支持句之间必须有显性逻辑标记**：读者应该能从过渡词判断论证方向
2. **禁止并列堆砌**："A found X. B found Y. C found Z." 是罗列，不是论证
3. **每个证据必须有理论钩子**：不是"Smith (2020) found..."，而是"Consistent with our attention-allocation mechanism, Smith (2020) found that..."
4. **证据必须服务于本段主题句**：如果某个证据不能直接支撑当前主题句，移到另一段或删除

## 反例 → 正例

- ❌ （并列堆砌，无逻辑链条）
  "CEO narcissism affects recall timing. Chatterjee and Hambrick (2007) found narcissistic CEOs use more first-person pronouns. Ridge et al. (2024) found narcissism is associated with risk-taking. Our results show a positive coefficient."
- ✅ （环环相扣的论证链）
  "CEO narcissism accelerates recall timing through an attention-allocation mechanism: narcissistic CEOs' heightened sensitivity to public image directs cognitive resources toward reputation-threatening signals, compressing the gap between defect detection and public disclosure. *（Layer 1: 理论阐释）* Consistent with this mechanism, our text-analysis measure of narcissism is positively associated with faster recall initiation (β = -0.23, p < 0.01). *（Layer 2: 实证支撑）* This effect is further strengthened in high-media-coverage periods, suggesting that narcissistic CEOs accelerate recalls not because they care more about safety, but because delays would contradict their self-constructed image of infallibility. *（Layer 3: 分析论证）* Moreover, the effect disappears when media attention is low, providing additional evidence that image concern—rather than genuine risk awareness—drives the relationship. *（递进：添加新维度）*"

## 段落四大误区警示

| 误区 | 症状 | 修复 |
|------|------|------|
| **观点分散** | 单段落加入过多核心观点 | 删除边缘论点，每个段落只服务一个主题句 |
| **内容单薄** | 一两句话构成段落 | 补充理论阐释、实证数据或权威引证 |
| **表达混乱** | 人称、时态前后不一 | 完稿后通篇检查风格统一性 |
| **衔接生硬** | 段落间跳跃，缺乏过渡 | 增加过渡句，明确逻辑关系 |
